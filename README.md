# Real-Time Webcam AI Vision Prototype 🎯📷

A lightweight, high-performance computer vision application that performs real-time object detection using your laptop's built-in webcam. Built with **Python**, **OpenCV**, and **YOLO**, this project runs entirely locally on edge hardware without needing external cloud APIs or GPU clusters.

![YOLO](https://img.shields.io/badge/YOLO-Ultralytics-orange)
![License](https://img.shields.io/badge/License-MIT-lightgrey)

---

## Key Features

* **Real-Time Detection:** Smooth object classification and bounding box localization directly from a webcam feed.
* **80 Pre-Trained Classes:** Detects common everyday objects (people, laptops, cell phones, chairs, cups, etc.) out of the box using COCO dataset weights.
* **100% Local Execution:** Runs edge AI on local CPU hardware—no cloud connectivity or API keys required.
* **Zero Boilerplate:** Under 20 lines of clean, readable, and extensible Python code.

---

## Tech Stack

* **[Python](https://www.python.org/):** Core programming language.
* **[Ultralytics YOLO](https://docs.ultralytics.com/):** Computer vision model for real-time inference.
* **[OpenCV](https://opencv.org/):** Real-time frame processing and video display GUI.
